🥇 Paris Olympic 2024 Dashboard
An interactive Power BI dashboard providing a comprehensive analysis of the **Paris 2024 Olympics**.  
This project explores medal distribution, athlete performance, and historical trends across countries and categories.

📊 Overview
The dashboard consists of **four pages**, each offering unique insights:

1. Overview Page – Displays total medals, country-wise breakdowns, gender distributions, and key event summaries.  
2. Country Page – Enables in-depth exploration of each nation’s performance, including medal types and rankings.  
3. Athletes Page – Highlights top-performing athletes with interactive filters for events, gender, and country.  
4. Historical Page – Compares Paris 2024 with previous Olympics to uncover long-term performance trends.

# Tools Used
- **Power BI** – Data modeling, visualization, and interactivity  
- **Excel** – Data cleaning and preparation  

# Key Insights
- Identifies medal dominance by leading nations.  
- Tracks gender participation and success rates.  
- Visualizes Olympic progress across decades.
