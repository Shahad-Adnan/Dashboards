🌦️ Weather Dashboard for Five Districts

A modern and interactive Weather Dashboard that provides real-time and 7-day forecast data for five districts using a Weather API. The dashboard displays temperature, humidity, air quality, and chemical composition insights with useful suggestions based on weather conditions.

# Features
  Real-time Weather Updates: Live data fetched via Weather API.
  7-Day Forecast: View upcoming trends in temperature, humidity, and conditions.
  Chemical Quality Insights: Check air and environmental chemical quality levels.
  Clean Visuals: Dashboard built with clear data visualization for better insights.

Data Source: https://www.weatherapi.com/
